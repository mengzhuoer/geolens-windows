# GeoLens 本地版（Windows 桌面软件）

**一句话说明**：把开源的 GeoLens 空间数据目录做成一个 Windows 程序。你只需要把遥感影像拖进启动目录里的「影像导入」文件夹，程序会自动整理、入库，随后可在网页里检索、预览、切片和出图。

- 原始项目：<https://github.com/geolens-io/geolens>（Apache-2.0，本项目是你的 fork `mengzhuoer/geolens`）
- 本软件完全离线运行，不依赖 Docker，不上传任何数据。
- 本打包版**没有登录步骤**：打开网页即自动进入本地管理员账户。
- 默认只监听 `127.0.0.1`（本机回环）；需要局域网访问时用带「局域网」字样的启动脚本，只额外开放网页端口 8081。

---

## 1. 启动

**双击安装目录里的 `GeoLens.exe` 就行**——前后端已经合并成一个程序、一个端口：

1. 立刻弹出一个 GeoLens 窗口，显示启动进度（数据库 → API → 切片 → 任务队列）；
2. 就绪后自动进入数据目录（<http://127.0.0.1:8080>），无需登录；
3. 窗口右下角有一条小浮条：**控制台**（服务状态、影像库设置、局域网）和 **退出**；
4. 点 **退出** 两次（第一次变成“确认退出”）会停止全部服务，包括数据库；关闭窗口本身不会停服务，下次双击会直接复用已运行的实例。

- 想改用内嵌窗口而不是 Edge 应用窗口：退出程序后，把 `data\config.json` 里 `"ui": {"mode": "webview"}`，再启动。
- 首次启动若 Windows 弹出“是否允许程序访问网络”，请允许 **专用网络/本机**。程序默认只连接 `127.0.0.1`。

### 局域网访问

在浮条点 **控制台 → 概览 → 局域网访问**，勾选并保存；控制台会显示形如 `http://192.168.1.5:8080` 的地址，其他设备打开即可。控制台本身始终只允许本机访问。

### 命令行 / 分离模式（高级）

需要把网页托管到另一台机器、或想用命令行看日志时，仍有：

- **启动.bat**：一个命令行窗口启动全部服务，网页在 <http://127.0.0.1:8081>；按 `Ctrl+C` 全部停止。
- **启动-局域网.bat**：同上，并把网页开到局域网。
- **启动后端.bat** / **启动网页.bat**：前后端各一个进程，便于单独重启调试；局域网版本对应 `-局域网` 后缀。

> `GeoLens.exe` 与 `.bat` 不要同时启动同一份 `data\`（数据库端口会冲突）。需要并行测试时，用环境变量 `GEOLENS_DESKTOP_DATA` 指向另一个数据目录。

首次启动会自动完成（约 20–35 秒，取决于磁盘和杀毒软件）：

1. 初始化内置 PostgreSQL 集群；
2. 创建 `geolens` 数据库并启用 PostGIS、pgvector、pg_trgm、unaccent 扩展；
3. 执行数据库迁移（之后启动会检测版本并跳过）；
4. **并行**启动 API、影像切片、入库任务队列；
5. 显示进度页，就绪后自动进入数据目录；启动期间窗口不会卡死。

> 之后的正常启动通常约 8–15 秒。

## 2. 无需登录

本打包版已取消登录门槛：打开程序后会自动以本地管理员身份进入，直接可以看到全部数据集和地图；局域网内其他设备打开 `http://<本机IP>:8080` 也一样，不需要账号密码。

> 这意味着**任何能访问 8080 端口的人都有完整管理权限**（可导入、修改、删除数据）。请只在可信的本机/局域网使用，不要把 8080 映射到公网。

需要恢复原来的登录界面时，把 `data\config.json` 里 `server.auto_login` 改为 `false` 后重启（发行包默认开启）。

## 3. 拖放影像入库

启动目录里只有一个影像文件夹：

```text
GeoLens\
  启动.bat
  影像导入\        ← 把遥感影像拖到这里
```

1. 把 `.tif/.tiff`（含 BigTIFF）、`.img`（ENVI）、`.jp2`、`.vrt`、`.shp`（连同 `.dbf/.shx/.prj`）、`.gpkg`、`.geojson`、`.fgb`、`.kml/.kmz` 等直接拖进 **影像导入**；
2. 程序每 **15 秒**检查一次，发现新文件会自动复制到 `data\library` 并入库；
3. 入库完成后网页目录里就会出现该数据集，可预览、出图、切片；重复文件会按内容指纹自动跳过；
4. 原文件会保留在「影像导入」里（复制模式）；确认入库后可自行删除，不影响已入库的数据。

> 本版本固定只扫描这一个文件夹（启动时自动写入配置并把扫描间隔设为 15 秒）。如需恢复多目录/网络目录扫描，把 `data\config.json` 的 `library.single_folder` 改为 `false`，再在控制台「本地影像库设置」里添加目录。

## 3.1 多时相预览

打开任意栅格数据集详情页，地图下方会出现 **多时相预览**（同一区域、标题去掉月份年份后相同的影像会自动归为一组）：

- **缩略图条**：按月份排列，点击即可切换时相；`←` / `→` 或左右箭头按钮快速前后翻。
- **中间地图**：显示当前时相的影像和整组影像的覆盖范围；点击地图色块会列出该位置覆盖的所有时相，点选即可定位到对应文件。
- **对应文件**：显示该时相的影像库路径，可复制；本机访问时还有 **在文件夹中定位**，会直接在资源管理器中选中该文件。
- **打开该数据集**：跳到该时相的正式详情页。
- 16 位/浮点影像的预览默认使用 2–98% 百分位拉伸，不再整片发黑。

> 同一区域如果存在早期失败重试留下的同名重复数据集，时间条会自动按“标题 + 时间”去重，只显示一个时相。

## 4. 配置「本地影像库」（高级）

默认单文件夹模式不需要配置。需要多目录扫描或调整整理方式时，切到控制台的 **本地影像库设置** 标签：

1. **自动扫描的文件夹**：点“浏览…”弹出文件夹选择框，或直接粘贴路径。
   - 点 **添加并保存** 后**立即写入配置**，不会再出现“加了却没生效”的情况；
   - 列表里每一项右侧的“移除”也会立即保存；
   - 支持一次粘贴带引号的路径（会自动去掉引号）。
2. **指定文件夹立即扫描**（新增）：只扫描这一次，**不加入**自动扫描列表。
   - 选好文件夹后点“立即扫描”，下方会实时显示“已发现 N 个 / 已处理 M 个 / 已遍历 K 个目录 / 当前文件”；
   - 扫描过程中可点“停止扫描”，通常 1–3 秒内停下。
3. **影像库目录**：所有找到的影像会被复制/移动到这里，默认是安装目录下的 `data\library`。
4. **整理方式**：
   - 复制（推荐）：原文件保留；
   - 移动：原文件移入影像库；
   - 硬链接：同一块磁盘时几乎不占额外空间（跨磁盘自动退化为复制）。
5. **整理后自动入库**：默认开启。关闭时只整理、不入库，之后可手动入库。
6. **ENVI/JP2/BMP 等转换为 GeoTIFF 后入库**：默认开启。
7. **扫描间隔**：默认 120 秒。新放进源文件夹的影像会在下一轮自动发现。
8. **跳过系统目录**：默认开启。全盘扫描时跳过 `Windows`、`WinSxS`、`Program Files`、
   `ProgramData`、`AppData`、`$Recycle.Bin` 等系统目录，否则扫一个盘要很久。
9. 顶部的 **「扫描本地影像」** 会先保存当前设置，再开始扫描。

> 全盘扫描提示：直接把盘符（如 `D:\`）加进源文件夹也可以，程序会边遍历边显示进度；
> 但一个盘可能有几十万文件，建议先用“指定文件夹立即扫描”确认某个目录的结果，再决定是否加入自动列表。

### 影像库的目录结构

```
data\library\
  D_遥感影像\           ← 源文件夹名（盘符+文件夹名）
    山西\
      shanxi_test.tif
      shanxi_test.tif.geolens.json   ← 自动生成的来源/指纹/数据集 ID 说明
```

- 保留源文件夹内的相对目录结构；
- 同名但内容不同的文件自动追加 `_1`、`_2`；
- 每个整理后的文件旁边生成 `.geolens.json`（记录原始路径、内容指纹、数据集 ID）。

### 去重与增量

- 用「文件大小 + 首尾 512KB」内容指纹（可在 `config.json` 里改成 `"hash_mode": "full"` 做全文件哈希）判断重复；
- 内容相同的文件只入库一次，其余标记为“重复”；
- 默认**不会在启动时立即扫描**（避免一开机就处理大目录）；每 120 秒定时扫描一次，可在设置里勾选“启动后立即扫描”；
- 未变化的文件下次扫描直接跳过；
- 失败的文件会在下次扫描时自动重试（修复版本后直接重新扫描即可）；
- 已经整理但未入库的文件（`auto_ingest` 关闭时）会保留记录。

### 支持的格式

| 类型 | 扩展名 | 说明 |
|---|---|---|
| 栅格 | `.tif` `.tiff` | 服务端自动转 COG；**支持 BigTIFF**（Sentinel-2 常见） |
| 栅格 | `.img`（+`.hdr`） | ENVI，自动转 GeoTIFF 后入库 |
| 栅格 | `.dat`（+`.hdr`） | ENVI，缺 `.hdr` 会跳过并说明原因 |
| 栅格 | `.jp2` `.bmp` `.grd` `.pix` `.ecw` `.sid` | 依赖 GDAL 驱动；可用时自动转 GeoTIFF |
| 矢量 | `.geojson` `.gpkg` `.shp` `.fgb` `.kml` `.kmz` `.parquet` | Shapefile 的 `.dbf/.shx/.prj/...` 会一起整理，并自动打包成 zip 后入库 |
| 需手动处理 | `.hdf` `.h4` `.hdf4` `.hdf5` `.nc` `.grib` `.zip` 等 | 多子数据集容器/压缩包：会跳过并记录，请先导出 GeoTIFF 或解压 |

源文件小于 `min_size_mb` 或大于 `max_size_mb`（默认 4096 MB）会被跳过并记录原因。可在设置中调整上限。


## 5. 局域网访问（让手机/其他电脑打开）

默认只允许本机访问。需要同一 Wi-Fi/局域网内的其他设备访问时：

1. 打开控制台 **概览 → 局域网访问**；
2. 勾选“允许同一局域网的设备访问”；
3. （可选）“对外地址”留空即可，程序会自动使用本机局域网 IP；也可以填 `192.168.1.20:8080` 或自定义主机名；
4. 点 **保存并应用**，程序会自动重启服务（约 15–25 秒），完成后卡片显示例如：
   `局域网地址：http://192.168.1.5:8080`
5. 其他设备用浏览器打开这个地址即可（需要 admin 登录）。

**防火墙**：首次监听局域网时，Windows 可能弹出“是否允许访问网络”，请勾选“专用网络”。
如果没有弹窗或仍连不上，点卡片里的 **“添加防火墙规则”**；若提示需要管理员权限，点
**“以管理员身份添加”**，在 UAC 弹窗点“是”。也可以手动以管理员运行：

```
netsh advfirewall firewall add rule name="GeoLens Desktop (LAN 8080)" dir=in action=allow protocol=TCP localport=8080
```

安全边界（重要）：

- 只对外开放 **8080 网页端口**；数据库 54329、API 8000、切片 8002、Worker 8003 仍然只监听 `127.0.0.1`；
- 控制台的 `/__desktop`（包含 admin 密码、扫描/退出等操作）**永远只允许本机访问**，局域网请求会返回 403；
- 局域网内其他人打开的是“数据目录”，仍需用户名密码登录；
- 本软件没有 HTTPS。**不要**把 8080 直接映射到公网；如需公网访问，请放在 VPN 或带 HTTPS 的反向代理之后；
- 请务必修改默认 admin 密码，并只在自己信任的网络中开启。

## 6. 使用数据

- 「数据目录」窗口就是 GeoLens 前端：搜索、数据集详情、地图构建器、版本历史、分享。
- 每个自动入库的影像是一个**私有数据集**，标题取自文件名，描述里写明来源路径与影像库路径。
- 数据集详情页的「连接 / QGIS」提供 OGC API、STAC、切片地址；QGIS 可直接连 `http://127.0.0.1:8080/api`。
- 别人在同一台电脑上无法访问：服务只绑定本机回环，登录仍需账号密码。

## 7. 数据、备份与迁移

所有状态都在安装目录的 `data\` 下：

```
data\
  config.json          ← 端口、管理员账号、扫描设置、随机密钥
  pgdata\              ← PostgreSQL 数据目录
  storage\             ← GeoLens 对象存储（COG、上传暂存）
  library\             ← 本地影像库（整理后的影像）
  logs\                ← 运行日志
  library-index.sqlite3← 扫描/入库账本
```

**备份**：先退出程序，再整体复制 `data\` 目录。
**迁移到新电脑**：安装后把旧机器的 `data\` 覆盖到新安装目录的同名位置即可（端口不变时无需改配置）。
**重置**：退出程序，删除 `data\`，重新启动会生成全新实例（影像库文件也会被删除，请先移走）。

## 8. 端口

| 端口 | 用途 | 绑定 |
|---|---|---|
| 8080 | 桌面窗口/网页前端、API 反向代理（`/api`） | 默认 127.0.0.1；开启局域网后 0.0.0.0 |
| 8000 | FastAPI 内部端口 | 127.0.0.1 |
| 8002 | TiTiler 影像切片 | 127.0.0.1 |
| 8003 | Worker 健康检查 | 127.0.0.1 |
| 54329 | PostgreSQL | 127.0.0.1 |

首次安装如果端口被占用，会自动顺延到下一个可用端口（写入 `data\config.json`）。

## 9. 常见问题

**启动慢 / 一直显示“启动中”**
首次启动要建库和迁移，约 30–60 秒。若超过 3 分钟，打开 `data\logs\desktop.log` 与 `data\logs\api.log` 查看原因；控制台会显示错误摘要。

**扫描发现 0 个文件**
- **先确认已经“添加并保存”**：控制台会自动保存，保存时间显示在输入框下方；
- 用「指定文件夹立即扫描」对单个目录做一次验证；
- 确认扩展名在“识别扩展名”列表中（逗号分隔、带点）；
- 文件大小是否超出上限；
- 压缩包（`.zip/.rar/.7z`）与 HDF/NetCDF 不会自动入库，需先解压或导出 GeoTIFF；
- 在「入库记录」里看是否被标为“跳过”及原因；
- 全盘扫描时系统目录（Windows/Program Files/AppData 等）会被默认跳过，属正常现象。

**入库失败**
查看「运行日志 → 入库任务」（`data\logs\worker.log`）。常见原因：文件损坏、CRS 缺失、磁盘空间不足。
矢量文件（GeoJSON/GPKG/SHP）写入 PostGIS 依赖 GDAL 的 PostgreSQL 驱动，本版本已内置；若仍失败，日志里会写明 `ogr2ogr` 的原始错误。

**想换管理员密码**
登录数据目录后在账号设置中修改；控制台显示的初始密码仅在首次生成时有效。若忘记密码，可在退出程序后删除 `data\pgdata` 重建（会丢失目录数据），或使用 `runtime\pgsql\bin\psql` 直接改库。

**卸载**
控制面板“应用和功能”里的 GeoLens 本地版卸载；卸载时会询问是否同时删除 `data\`（默认保留）。

**杀毒软件报警**
这是 PyInstaller 打包的未签名 exe，部分杀软会误报。可加入信任，或直接运行目录里的 `GeoLens.exe`。

## 10. 技术栈

- GeoLens 1.29.2（FastAPI + React + MapLibre）
- PostgreSQL 16.15（EDB 官方 Windows 构建）
- PostGIS 3.6.2、pgvector 0.8.6（HNSW 可用）
- Python 3.13 + GDAL 3.13.3 + rasterio + TiTiler 2.4.0
- 桌面外壳：独立后台服务 + 系统浏览器（可选 pywebview/WebView2）+ PyInstaller
- 单端口反代：内置 Python HTTP 代理（等价于官方 nginx 路由）

第三方许可证见 `THIRD_PARTY-LICENSES.md`。
